# data/seeds/

Hand-written, high-quality bootstrap problems, one file per reasoning type (`{type}.seeds.jsonl`). Used to seed the Generator (PIPELINE.md). Never drawn from eval splits. Items generated from a seed reference it via `provenance.seed_id`. See DATA.md for the full layout and invariants.

Currently empty: the initial batch was delivered directly to `data/curated/`. Hand-written seeds will be added here when they are used to bootstrap further generation.
